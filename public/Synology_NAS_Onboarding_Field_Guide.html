Synology NAS On-Site Configuration & Field Guide

Target System: StillWorks LegalOS Enterprise Storage • Protocol: Synology WebDAV Server • Author: Implementation Team

This field guide provides an exact, step-by-step walkthrough for setting up an office Synology NAS as the secure document repository for StillWorks LegalOS during an on-site visit.

Phase 1 Pre-Visit Preparation

  • Master Credentials: Ask the managing partner or office manager who has the administrator password for the Synology NAS and office Wi-Fi router.
  • Diagnostic Laptop: Your laptop with StillWorks LegalOS installed and web browser ready.
  • Network Cable: Standard Cat6 Ethernet cable in case Wi-Fi is restricted.
  • Utility Tool: Download free Synology Assistant on your laptop.

Phase 2 Discover the NAS on the Office Network

  1. Connect your laptop to the office Wi-Fi or office network switch.
  2. Open your browser and navigate to:
    http://find.synology.com
    (Or open Synology Assistant and click "Search".)
  3. Look for the entry showing:
    • Model: (e.g. DS220+, DS920+, DS423+)
    • IP Address: (e.g. 192.168.1.50 or 192.168.0.120)
    • Status: Ready
  4. Click Connect or navigate to http://<NAS_IP>:5000.

Phase 3 Set a Static (Permanent) IP

Important: If the router restarts, dynamic DHCP could assign a new IP address, breaking the document link. Setting a static IP prevents this.
  1. Log into DSM (DiskStation Manager) using the master administrator credentials.
  2. Open Control Panel → Network → Network Interface.
  3. Select LAN 1 and click Edit.
  4. Select "Use manual configuration".
  5. Keep the current IP Address, Subnet Mask, and Gateway. Set DNS Server to 1.1.1.1.
  6. Click OK.

Phase 4 Install and Enable WebDAV Server

  1. Open Package Center from the DSM desktop.
  2. Search for "WebDAV Server".
  3. If not installed, click Install. If already installed, click Open.
  4. In the configuration dialog:
    • Check Enable HTTP (Port: 5005)
    • Check Enable HTTPS (Port: 5006)
  5. Click Apply.

Phase 5 Create the Shared Folder for LegalOS

  1. Open Control Panel → Shared Folder.
  2. Click Create → Create Shared Folder.
  3. Configure the folder:
    • Name: LegalOS
    • Description: StillWorks LegalOS Document Repository
    • Location: Volume 1 (or the primary storage pool)
  4. Click Next through the wizard and click Apply.

Phase 6 Create the Dedicated Service Account

Security Best Practice: Never use the master admin account inside the application. A dedicated service user isolates application access.
  1. Open Control Panel → User & Group.
  2. Click Create → Create User.
  3. Set account details:
    • Name: legalos_svc
    • Password: (Create a strong 16+ character password and record it below)
  4. Advance to Shared Folder Permissions:
    • Find the LegalOS folder and check Read/Write.
  5. Advance to Applications:
    • Find WebDAV Server and check Allow.
  6. Click Done to save.

Phase 7 Deployment Architecture

Scenario A: Local Office Deployment (Server inside office)

If the LegalOS server runs on an office computer or local mini-server on the same Wi-Fi/LAN:

  • WebDAV URL: http://<LOCAL_NAS_IP>:5005 (e.g. http://192.168.1.50:5005)
  • Port Forwarding: Not needed.

Scenario B: Cloud VPS Deployment (Server on DigitalOcean / AWS / Hetzner)

If the LegalOS server is hosted on a cloud VPS, it must reach the office NAS over the internet:

  1. Enable Free Synology DDNS:
    • In DSM, go to Control Panel → External Access → DDNS → Add.
    • Service Provider: Synology • Hostname: [firmname].synology.me
    • Check "Request Let's Encrypt SSL certificate" and save.
  2. Forward Port on Office Router:
    • Log into the office router (e.g. 192.168.1.1).
    • In Port Forwarding, forward external port 5006 (TCP) to internal NAS IP 5006.
  3. WebDAV URL: https://[firmname].synology.me:5006

Phase 8 Live Handshake & Verification Test

  1. Open StillWorks LegalOS on your laptop and log in as Admin.
  2. Go to Admin Settings → Storage.
  3. Enter:
    • WebDAV URL: http://192.168.1.50:5005 (or https://[firmname].synology.me:5006)
    • Username: legalos_svc
    • Password: [Password created in Phase 6]
    • Root folder: /LegalOS
  4. Click "Test Connection". Confirm the green checkmark appears.
  5. Click "Save changes".
  6. Live Upload Test: Upload any PDF under Cases or Documents. Open Synology File Station, navigate into /LegalOS, and verify the file is stored.
